# Invent India TMT Library

A static, public-safe shell for the Invent India TMT Library.

## Run locally

Open `index.html` in a browser. The library starts with an empty catalog; use
the Upload Docs panel to add files for the current browser session.

## Content and privacy

This repository intentionally excludes internal business materials, customer
responses, proposals, and document metadata. Add only content that has been
reviewed and cleared for public distribution.
